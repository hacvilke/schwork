# Schwork

Free, open-source, **phone-first** study documentation for Jamaican high school students (Grades 10–11) — built one subject at a time.

## Local Development

```bash
npm install
npm start
```

### Production Builds

```bash
# Vercel build (baseUrl '/')
npm run build

# GitHub Pages build (baseUrl '/schwork/')
npm run build:gh-pages

# Serve built site locally
npm run serve

# Type check
npm run typecheck
```

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the lesson authoring template, Matplotlib SVG workflow, and dual deployment setup, and [CREDITS.md](./CREDITS.md) for legal/trademark notices and acknowledgements.
