## 2. Master Translation Table: Pseudocode → Pascal, Python & C

### A. Declarations, Assignment & Input / Output

| Construct | Pseudocode | **Pascal** | **Python** | **C** |
| :--- | :--- | :--- | :--- | :--- |
| **Constant** | `CONST TAX = 0.15` | `CONST tax = 0.15;` | `TAX = 0.15` *(convention)* | `const float TAX = 0.15;` |
| **Declare Integer / Real** | `age: Integer`<br/>`price: Real` | `VAR age: integer;`<br/>`price: real;` | *(Dynamic — assigned on use!)*<br/>`age = 0; price = 0.0` | `int age;`<br/>`float price;` |
| **Declare Char / String / Boolean** | `grade: Char`<br/>`name: String`<br/>`ok: Boolean` | `grade: char;`<br/>`name: string;`<br/>`ok: boolean;` | `grade = 'A'`<br/>`name = ""`<br/>`ok = True` | `char grade;`<br/>`char name[50];`<br/>`bool ok;` *(`<stdbool.h>`)* |
| **Assignment** | `Total ← 0` | `total := 0;` | `total = 0` | `total = 0;` |
| **Keyboard Input** | `READ age`<br/>`READ price` | `readln(age);`<br/>`readln(price);` | `age = int(input())`<br/>`price = float(input())` | `scanf("%d", &age);`<br/>`scanf("%f", &price);` |
| **Screen Output** | `PRINT "Total:", total` | `writeln('Total: ', total:0:2);` | `print("Total:", total)` | `printf("Total: %.2f\n", total);` |

### B. Operators (Arithmetic, Relational & Logical!)

| Operation | Pseudocode | **Pascal** | **Python** | **C** |
| :--- | :---: | :---: | :---: | :---: |
| **Integer Division (`DIV`)** | `17 DIV 5` | `17 div 5` | `17 // 5` | `17 / 5` *(both ints!)* |
| **Remainder (`MOD`)** | `17 MOD 5` | `17 mod 5` | `17 % 5` | `17 % 5` |
| **Equals (Comparison!)** | `x = 10` | `x = 10` | **`x == 10`** | **`x == 10`** |
| **Not Equal** | `x <> 0` | `x <> 0` | `x != 0` | `x != 0` |
| **Logical AND / OR / NOT** | `AND`, `OR`, `NOT` | `and`, `or`, `not` *(wrap sub-conditions in `()`!)* | `and`, `or`, `not` | `&&`, `\|\|`, `!` |

### C. Selection (`IF-THEN-ELSE` & `CASE`) and Iteration (`FOR`, `WHILE`, `REPEAT`)

| Control Structure | **Pascal** | **Python** | **C** |
| :--- | :--- | :--- | :--- |
| **`IF-THEN-ELSE`** | `if score >= 50 then`<br/>`  writeln('Pass')`<br/>`else`<br/>`  writeln('Fail');` | `if score >= 50:`<br/>`    print("Pass")`<br/>`else:`<br/>`    print("Fail")` | `if (score >= 50) {`<br/>`  printf("Pass\n");`<br/>`} else {`<br/>`  printf("Fail\n");`<br/>`}` |
| **`CASE` / Multi-Way** | `case grade of`<br/>`  'A': writeln('Top');`<br/>`  'B': writeln('Good');`<br/>`else writeln('Try');`<br/>`end;` | `match grade:` *(or `if/elif/else`)*<br/>`    case 'A': print("Top")`<br/>`    case _: print("Try")` | `switch (grade) {`<br/>`  case 'A': printf("Top"); break;`<br/>`  default: printf("Try");`<br/>`}` |
| **`FOR` Loop** *(1 to 5)* | `for i := 1 to 5 do`<br/>`begin`<br/>`  ...`<br/>`end;` | `for i in range(1, 6):`<br/>`    ...` *(Watch: `6` is exclusive!)* | `for (i = 1; i <= 5; i++) {`<br/>`  ...`<br/>`}` |
| **`WHILE` Loop** *(Pre-test)* | `while num <> 0 do`<br/>`begin`<br/>`  ...`<br/>`end;` | `while num != 0:`<br/>`    ...` | `while (num != 0) {`<br/>`  ...`<br/>`}` |
| **`REPEAT` Loop** *(Post-test)* | `repeat`<br/>`  readln(score);`<br/>`until (score>=0) and (score<=100);` | `while True:`<br/>`    score = int(input())`<br/>`    if 0 <= score <= 100:`<br/>`        break` | `do {`<br/>`  scanf("%d", &score);`<br/>`} while (score < 0 \|\| score > 100);` |

> **Excel VBA Quick Note (for VBA SBA Schools!):** In Excel VBA, declare with `Dim total As Double`, `Const GCT As Double = 0.15`, read with `InputBox("Enter price:")`, display with `MsgBox "Total: " & total`, branch with `If score >= 50 Then ... Else ... End If`, and loop with `For i = 1 To 5 ... Next i` or `Do While num <> 0 ... Loop`!

## 3. Worked Example: Translating ONE Complete Exam Algorithm into Pascal, Python & C!

<WorkedExample
  title="Complete Side-by-Side Working Program — Jamaican Store Checkout (Sentinel WHILE Loop + Discount)"

      <br />
      <em>Accept item prices from a cashier until <strong><code>0</code></strong> is entered (sentinel). Sum all valid prices into <code>Total</code> and count items in <code>Count</code>.     </>
  }
  examTip="Notice THREE SBA full-mark habits built into ALL THREE implementations below: (1) Always declare and INITIALISE accumulators (total = 0, count = 0) BEFORE the loop; (2) Always prompt clearly before reading input; (3) Include a priming read before the WHILE loop AND a matching read at the bottom of the loop!"
>

### Version A — Complete **Pascal** Implementation

```pascal
program StoreCheckout;
{ Author: Schwork Student | Calculates item total with 10% discount at J$5,000+ }
const
  DISC_RATE = 0.10;
var
  price, total, discount, finalTotal: real;
  count: integer;
begin
  total := 0.0;
  count := 0;

  write('Enter item price (0 to finish): ');
  readln(price);

  while price <> 0 do
  begin
    total := total + price;
    count := count + 1;
    write('Enter next item price (0 to finish): ');
    readln(price);
  end;

  if total >= 5000 then
    discount := total * DISC_RATE
  else
    discount := 0.0;

  finalTotal := total - discount;

  writeln('Items purchased : ', count);
  writeln('Discount (J$)   : ', discount:0:2);
  writeln('Final Total (J$): ', finalTotal:0:2);
end.
```

### Version B — Complete **Python** Implementation

```python
# Author: Schwork Student | Calculates item total with 10% discount at J$5,000+
DISC_RATE = 0.10

total = 0.0
count = 0

price = float(input("Enter item price (0 to finish): "))

while price != 0:
    total = total + price
    count = count + 1
    price = float(input("Enter next item price (0 to finish): "))

if total >= 5000:
    discount = total * DISC_RATE
else:
    discount = 0.0

final_total = total - discount

print(f"Items purchased : {count}")
print(f"Discount (J$)   : {discount:.2f}")
print(f"Final Total (J$): {final_total:.2f}")
```

### Version C — Complete **C** Implementation

```c
/* Author: Schwork Student | Calculates item total with 10% discount at J$5,000+ */
#include <stdio.h>

int main(void) {
    const double DISC_RATE = 0.10;
    double price, total = 0.0, discount = 0.0, finalTotal = 0.0;
    int count = 0;

    printf("Enter item price (0 to finish): ");
    scanf("%lf", &price);

    while (price != 0) {
        total = total + price;
        count = count + 1;
        printf("Enter next item price (0 to finish): ");
        scanf("%lf", &price);
    }

    if (total >= 5000) {
        discount = total * DISC_RATE;
    } else {
        discount = 0.0;
    }

    finalTotal = total - discount;

    printf("Items purchased : %d\n", count);
    printf("Discount (J$)   : %.2f\n", discount);
    printf("Final Total (J$): %.2f\n", finalTotal);
    return 0;
}
```
