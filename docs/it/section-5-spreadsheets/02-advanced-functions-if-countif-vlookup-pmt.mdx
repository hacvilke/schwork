## 1. The `IF` Function (Tested Almost EVERY SINGLE YEAR on Paper 2!)

The **`IF`** function makes a **logical decision** — testing a condition and returning **one result if TRUE** and a **different result if FALSE**!

<FormulaCard
  title="IF Function Syntax (3 Mandatory Arguments)"
  onFormulaSheet={false}
  summary="=IF(logical_test, value_if_true, value_if_false) — wrap text outputs in double quotes like &quot;Pass&quot;, NEVER wrap numbers or calculations in quotes!"
>

```excel
=IF(logical_test, value_if_true, value_if_false)
```

- **`logical_test`:** A comparison using `=`, `<>`, `>`, `<`, `>=`, `<=` (e.g. `B2>=50` or `C2="Yes"`).
- **`value_if_true`:** What Excel displays/calculates when the test is **TRUE**.
- **`value_if_false`:** What Excel displays/calculates when the test is **FALSE**.

</FormulaCard>

### Examples (Simple `IF` & Nested `IF`!)
- **Text Decision:** `=IF(C2>=50, "Pass", "Fail")`
- **Numeric Calculation (10% Discount if Total > J\$10,000):** `=IF(D2>10000, D2*0.10, 0)`
- **Nested `IF` (3 Outcomes — Grades A, B, or C):**
  ```excel
  =IF(B2>=80, "A", IF(B2>=60, "B", "C"))
  ```
  *(Count your brackets! Two `IF(` openings require **TWO closing `))`** at the end!)*

## 2. The `COUNTIF` Function (Conditional Counting!)

Unlike `COUNT` (which counts *all* numbers), **`COUNTIF`** counts **ONLY the cells inside a range that meet ONE specific condition (criterion)**!

```excel
=COUNTIF(range, criteria)
```

### Four Classic Exam Patterns for `COUNTIF`
1. **Exact Text Match:** `=COUNTIF(C2:C25, "Kingston")` → counts how many customers live in Kingston!
2. **Comparison Operator (MUST be inside `"..."` quotes!):** `=COUNTIF(D2:D25, ">=50")` → counts how many students passed (scored 50 or more)!
3. **Comparing Against Another Cell:** `=COUNTIF(D2:D25, ">"&$F$1)` → counts scores higher than the cutoff stored in cell `$F$1`!
4. **Bonus Partner (`SUMIF`):** `=SUMIF(C2:C25, "Kingston", E2:E25)` → sums ONLY the sales in `E2:E25` where the parish in `C2:C25` equals `"Kingston"`!

## 3. The `VLOOKUP` Function (**SBA & Paper 2 Goldmine!**)

**`VLOOKUP`** (*Vertical Lookup*) searches **down the FIRST (leftmost) column** of a reference table for a lookup value, then walks straight across that matching row to pull back a value from another column!

```excel
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
```

| Argument | Plain-English Meaning | Golden Exam Rule! |
| :--- | :--- | :--- |
| **1. `lookup_value`** | The code/score you want to search for (e.g. `A4` = `"P02"` or `B4` = `74`). | Must match values in the **1st column** of `table_array`! |
| **2. `table_array`** | The entire lookup table range (e.g. `$G$2:$I$6`). | **ALWAYS lock with `$` absolute references** so copying down never slides the lookup table! |
| **3. `col_index_num`** | The **column number** inside `table_array` holding the answer (`1` = 1st col, `2` = 2nd col, `3` = 3rd col). | Count from the **left edge of the table**, NOT from Excel's Column A! |
| **4. `range_lookup`** | **`FALSE` (Exact Match)** vs **`TRUE` (Approximate Range Match)**! | • Use **`FALSE`** for **IDs, Product Codes, Names** (exact match only — throws `#N/A` if missing!).<br/>• Use **`TRUE`** for **Grade Bands / Tax Brackets** (`0→F, 50→C, 65→B, 80→A`) — **1st column MUST be sorted ASCENDING!** |

## 4. The `PMT` Function (Monthly Loan / Mortgage Payments!)

The **`PMT`** (*Payment*) function calculates the **constant periodic payment** needed to repay a loan (like a car loan, student loan, or NHT mortgage!) at a fixed interest rate!

```excel
=PMT(rate, nper, pv)
```

| Argument | What It Means | **CRITICAL Monthly Loan Exam Trap!** |
| :--- | :--- | :--- |
| **`rate`** | Interest rate **PER PAYMENT PERIOD** | If an exam gives **12% ANNUAL interest** paid **MONTHLY**, you MUST divide by 12 → **`12%/12`** (or `B2/12`)! |
| **`nper`** | **Total number of payment periods** | For a **5-year loan paid MONTHLY**, you MUST multiply by 12 → **`5*12`** (= `60` months, or `C2*12`)! |
| **`pv`** | **Present Value** (Loan Principal borrowed) | Put a **minus sign (`-pv`, e.g. `-500000`)** so Excel displays a clean positive payment (otherwise Excel displays cash outflow in red/negative `(J$11,122.22)`)! |

**Example:** Monthly payment on a **J\$600,000** loan at **12% annual interest** over **5 years**:
```excel
=PMT(12%/12, 5*12, -600000)
```
*(Or referencing cells `B2=12%`, `C2=5`, `D2=600000`: `=PMT(B2/12, C2*12, -D2)` → returns **J\$13,346.67 per month**!)*

## 5. Worked Example: Complete Paper 2 Function Challenge (`IF`, `COUNTIF`, `VLOOKUP`, `PMT`)

<WorkedExample
  title="Caribbean Tech Academy — Student Grades, VLOOKUP & Equipment Loan Sheet"
  marks={12}
  problem={
    <>
      A worksheet holds 20 students in Rows <strong><code>2</code> to <code>21</code></strong>: <code>A</code> = StudentName, <code>B</code> = Score, <code>C</code> = Status (<code>"Pass"</code> if Score ≥ 50 else <code>"Fail"</code>), <code>D</code> = Grade Letter looked up from table <strong><code>$G$2:$H$5</code></strong>:
      <br />
      <code>G2: 0 | H2: "F"</code> &nbsp;·&nbsp; <code>G3: 50 | H3: "C"</code> &nbsp;·&nbsp; <code>G4: 65 | H4: "B"</code> &nbsp;·&nbsp; <code>G5: 80 | H5: "A"</code>
      <br />
      Write the exact Excel formula for:
      <br />
      (a) Cell <code>C2</code> (Status using <code>IF</code>).
      <br />
      (b) Cell <code>D2</code> (Grade Letter using <code>VLOOKUP</code>, safe to replicate down to <code>D21</code>!).
      <br />
      (c) Cell <code>B23</code> (Number of students who scored <strong>80 or above</strong> using <code>COUNTIF</code>).
      <br />
      (d) The academy borrows <strong>J$1,200,000</strong> (cell <code>H10</code>) at <strong>9% annual interest</strong> (cell <code>H11</code>) for <strong>4 years</strong> (cell <code>H12</code>) paid <strong>monthly</strong>. Write the <code>PMT</code> formula in <code>H13</code> to show a positive monthly repayment!
    </>
  }
  examTip="Look closely at VLOOKUP's 4th argument in (b): because a score like 74 falls BETWEEN 65 and 80 (it is NOT an exact key in G2:G5!), you MUST use TRUE (approximate match) with G2:G5 sorted ascending — FALSE would return #N/A for 74!"
>

| Part & Cell | Exact Formula | Quick Verification |
| :--- | :--- | :--- |
| **(a) `C2` (`IF`)** | `=IF(B2>=50, "Pass", "Fail")` | Score `74` → `"Pass"`; Score `42` → `"Fail"`. |
| **(b) `D2` (`VLOOKUP`)** | `=VLOOKUP(B2, $G$2:$H$5, 2, TRUE)` | Score `74` matches highest threshold ≤ 74 (`65`) → pulls Col 2 = **`"B"`**! `$G$2:$H$5` stays locked on copy! |
| **(c) `B23` (`COUNTIF`)** | `=COUNTIF(B2:B21, ">=80")` | Notice `">=80"` wrapped strictly inside double quotes! |
| **(d) `H13` (`PMT`)** | `=PMT(H11/12, H12*12, -H10)` | Converts 9% annual → monthly (`H11/12`), 4 years → 48 months (`H12*12`), and `-H10` gives a positive J\$ repayment! |

</WorkedExample>
