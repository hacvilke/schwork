## 1. Formatting & Document Layout Features (Know Every Exact Distinction!)

A **word processor** (e.g. **Microsoft Word**, **LibreOffice Writer**, **Google Docs**) creates, edits, formats, stores, and prints professional documents — from business letters and brochures to your entire IT SBA!

### High-Frequency Formatting Terms Tested on Paper 1 & 2

| Feature | Exact Meaning & When to Use It |
| :--- | :--- |
| **Importing / Combining Text** | Inserting text, tables, or charts directly from another file (e.g. pasting an Excel chart into your SBA Word report or `Insert → Object → Text from File`). |
| **Superscript vs Subscript** | • **Superscript:** Raises small text *above* the baseline (e.g. $x^2$, `1st`, `25°C`).<br/>• **Subscript:** Lowers small text *below* the baseline (e.g. $\text{H}_2\text{O}$, $\text{CO}_2$). |
| **Text Justification (Alignment)** | • **Left:** Straight left edge, ragged right (casual/letters).<br/>• **Right:** Straight right edge (dates/totals).<br/>• **Centre:** Centred horizontally (titles/headings).<br/>• **Full Justify:** Straight on **BOTH left and right margins** (newspapers, formal reports!). |
| **Word Wrap** | Automatically moves a word that won't fit at the right margin down to the start of the next line — **never press `Enter` at the end of every line inside a paragraph!** |
| **Page Break vs Section Break** | • **Page Break:** Forces text onto a fresh new page while keeping the **SAME** margins/orientation.<br/>• **Section Break:** Splits the document into independent sections so Page 1 can be **Portrait** (standard letter) while Page 2 is **Landscape** (wide spreadsheet table) with its own headers/columns! |
| **Headers & Footers** | Repeated text/graphics printed automatically in the **top margin (Header)** or **bottom margin (Footer)** of every page (e.g. document title, school name, automatic **Page Numbers**). |
| **Footnote vs Endnote** | • **Footnote:** Reference note placed at the **bottom of the SAME page** where cited.<br/>• **Endnote:** Reference note collected together at the **VERY END of the entire document** (or chapter)! |
| **Tab Stops & Line Spacing** | **Tab Stops** align text neatly at set horizontal distances (`Left`, `Right`, `Decimal` tab stops for aligning J\$ amounts!); **Line Spacing** (`1.0`, `1.15`, `1.5`, `2.0 Double`) sets vertical breathing room between lines. |

## 2. Editing, Tables, Columns, Review & Document Protection

### A. Editing & Structuring Tools
- **Block Operations (Drag-and-Drop / Cut, Copy, Paste):** Highlighting a selected block of text to **Move (`Cut` + `Paste` or Drag)**, **Duplicate (`Copy` + `Paste`)**, delete, or reformat all at once!
- **Search (Find) & Replace (`Ctrl + H`):** Automatically locates every occurrence of a word/phrase across a 50-page document and replaces it accurately (e.g. changing `"2025"` → `"2026"` or fixing a misspelled client surname everywhere in one click!).
- **Tables:** Organising structured rows & columns — applying **table styles, shading, borders**, **inserting/deleting rows & columns**, **merging cells** (for a spanning table banner), **splitting cells / splitting tables**, changing **text direction**, and adjusting **cell size & cell margins**!
- **Newspaper Columns:** Splitting text flow into **1, 2, 3, Left, or Right columns** (ideal for school newsletters & brochures!) using a **Column Break** when you want text to jump cleanly to the top of the next column!

### B. Review Tools (Making Documents Error-Free!)
- **Spell & Grammar Check:** Flags misspelled words (red squiggle) and grammar mistakes (blue/green squiggle) — **IMPORTANT EXAM LIMITATION:** *Spell check will NOT catch a correctly spelled wrong word (homophone/typo), e.g. typing `"their"` instead of `"there"` or `"form"` instead of `"from"` — so you MUST still proofread!*
- **Thesaurus:** Suggests **synonyms** (similar-meaning words) and antonyms to enrich vocabulary.
- **Word Count & Language Setting:** Counts words/characters/paragraphs and sets **English (UK/Caribbean)** spelling (e.g. *colour*, *organise*) instead of US spelling!
- **Comments & Track Changes:** Lets a teacher or editor insert margin notes (**Comments**) and visibly highlight every insertion/deletion (**Track Changes**) so the author can **Accept** or **Reject** each edit!

### C. Document Protection & Automatic Table of Contents
- **Automatic Save & Backup Copy:** AutoRecover saves drafts periodically every few minutes in case JPS power cuts out or Word crashes!
- **Password Protection & Edit Restrictions:** Encrypts a sensitive file so a **Password to Open** is required, or sets **Read-Only / Password to Modify** so readers can view it without altering grades or contracts!
- **Automatic Table of Contents (Auto TOC):**
  1. Apply built-in **Heading Styles** (`Heading 1`, `Heading 2`, `Heading 3`) to every section title *(NEVER just manually make text bold and bigger — Auto TOC ignores manual bold text!)*.
  2. Click `References → Table of Contents → Automatic Table` — Word generates every heading and exact page number automatically, and **Update Table** refreshes page numbers in one click!

## 3. Mail Merge (**Top Paper 2 & SBA Mark-Earner!**)

**Mail Merge** automatically combines ONE template document with a list of individual records to produce **hundreds of personalised letters, certificates, envelopes, or mailing labels** in seconds!

### The Three Components of Every Mail Merge
1. **Primary Document (Main Document):** The standard template containing the **unchanging text** (e.g. school invitation letter) PLUS **Merge Field placeholders** like `«FirstName»`, `«LastName»`, `«Address»`, `«BalanceDue»`!
2. **Data Source (Data File):** A structured table containing the **unique variable details** for each recipient — usually an **Excel spreadsheet**, an **Access database table/query**, or a **Word table** (where every column header is a **Field Name** and every row is one recipient's **Record**)!
3. **Merged Output Document:** The final generated file containing one individual personalised copy for EVERY record in the data source (e.g. 150 unique parent letters ready to print or email)!

```text
  [PRIMARY DOCUMENT]                  [DATA SOURCE (Excel/Access)]
  Dear «Title» «LastName»,            Title | LastName | Balance
  Your balance is J$«Balance».   +    Ms.   | Campbell | 12,500
                                      Mr.   | Reid     |  8,000
                                                │
                                                ▼
                          [MERGED LETTERS — 2 Personalised Letters!]
                   Letter 1: Dear Ms. Campbell, Your balance is J$12,500.
                   Letter 2: Dear Mr. Reid, Your balance is J$8,000.
```

## 4. Fillable Electronic Forms (Content Controls — Syllabus Obj 4.8!)

Instead of printing paper forms that have to be hand-filled and re-typed, modern offices create **Fillable Electronic Forms** inside Word (via the **`Developer` tab**) or online forms using **Content Controls**:

| Content Control | Exact Purpose on an Electronic Form | Example Field |
| :--- | :--- | :--- |
| **Text Box (Plain / Rich Text)** | Allows user to type short or long free text. | `Full Name`, `Email Address`, `Home Address` |
| **Check Box** | Lets user tick **ZERO, ONE, OR MULTIPLE** independent choices! | `Subjects Taken: [✓] IT  [✓] Mathematics  [ ] Physics` |
| **Drop-Down List / Combo Box** | Lets user pick **ONE** valid option from a pre-set list (prevents spelling errors!). | `Parish: [Kingston ▼]` *(14 parishes pre-loaded!)* |
| **Date Picker** | Pops up a clickable calendar so dates always enter in a valid consistent format! | `Date of Birth: [14/05/2009 📅]` |
| **Command Button** | Triggers an action (e.g. `Submit Form`, `Clear / Reset`, or `Print` via macro/form action)! | `[ Submit Application ]` |

*(SBA Pro Tip: Restrict editing to **"Filling in forms"** once controls are placed so users can ONLY type inside the boxes without messing up your form questions!)*

### (a) Mail Merge Components
- **Word-Processing Feature:** **Mail Merge**
- **Primary Document:** The standard Prize-Giving invitation letter template containing the shared message and merge field placeholders.
- **Data Source:** The Excel workbook `Parents.xlsx` containing all 250 parent records and field names (`ParentTitle`, `ParentSurname`, `StudentName`, `AwardWon`).

### (b) Merge Field Greeting Line
- `Dear «ParentTitle» «ParentSurname»,`

### (c) Best Content Controls for the Fillable Form
- **(i) Attendance Date:** **Date Picker** *(ensures valid calendar date format)*
- **(ii) Parish of Residence:** **Drop-Down List** *(restricts selection to the 14 valid parishes, preventing typos!)*
- **(iii) Dietary Preferences (multiple allowed):** **Check Boxes** *(allows ticking zero, one, or multiple options independently!)*
