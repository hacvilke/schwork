## 1. Planning a Website Before Building It (Syllabus Objective 4.9!)

Just like writing an essay outline, good websites are **planned on paper BEFORE opening a web builder!** Every IT SBA and Paper 2 web-planning question looks for **FIVE planning elements**:

1. **Purpose / Reasons for the Website:** *Why does this site exist?* (e.g. inform voters of parish election results, showcase school club events, advertise a Jamaican bakery's menu and prices).
2. **Intended Audience:** *Who will visit it?* (e.g. high-school students, parents, tourists, local shoppers) — this guides your **language tone, font size, colour contrast, and device layout**!
3. **Number of Web Pages Desired:** For the IT syllabus & SBA, keep it focused — **no more than 3 pages** (e.g. `Home`, `Services / Results`, `Contact Us`)!
4. **Content of Each Page:** Decide exactly what text, tables, spreadsheet charts, and photos belong on each page so pages stay clean and uncluttered.
5. **Layout (Wireframe / Storyboard):** Sketch a rough box diagram showing where the **banner/logo, navigation bar, main text, wrapped images, and footer** sit consistently across all pages!

## 2. Creating Simple Web Pages Using Visual Tools (Syllabus Obj 4.10!)

> **Syllabus Note:** **Raw HTML coding is NOT required!** You build your site using user-friendly visual web design tools such as **Google Sites**, **Wix**, **Weebly**, **WordPress**, or **Microsoft Word (`Save As → Web Page .html`)**!

### Essential Page Design Features
- **Consistent Theme & Readable Contrast:** Pick clean dark text on a light background (or crisp light text on a dark banner), max 2–3 complementary brand colours, and legible sans-serif fonts!
- **Inserting & Deleting Text and Graphics:** Add sharp, relevant, non-stretched images (logos, charts exported from your SBA Spreadsheet!) with clear captions.
- **Wrapping Text Around Images:** Set image wrapping (`Square`, `Tight`, `Left/Right Align`) so paragraphs flow neatly beside photos instead of leaving awkward giant empty white gaps!
- **Clear Home Page (`index.html`) with Navigation Menu:** Visitors should immediately know what the site is about within 3 seconds and be able to click cleanly to every other page and back to **Home**!

## 3. All Four Types of Hyperlinks (MUST Know for Paper 1, 2 & SBA!)

A **hyperlink** turns text, a button, or an image into a clickable jump! The IT syllabus requires you to know and build **ALL FOUR hyperlink types**:

| Hyperlink Type | Where Clicking It Takes the User | Concrete SBA / Real-World Example |
| :--- | :--- | :--- |
| **1. Link to Another Web Page** *(Internal or External)* | Opens another page inside your own website **OR** an external website on the Internet! | Clicking `"View Results"` to open `results.html`, OR clicking `"Ministry of Education"` to open `https://moey.gov.jm`. |
| **2. Link to a Location WITHIN the Same Web Page** *(Bookmark / Anchor Link)* | Jumps smoothly up or down to a specific heading inside a long page! | Clicking `"Back to Top ↑"` at the bottom of the page, or clicking `"Section C"` in a mini menu to jump straight to that heading! |
| **3. Link to an Email Address** | Automatically launches the visitor's default email app with the **`To:` address pre-filled**! | Clicking `"Email Us"` linked to `mailto:info@bluepeakschool.edu.jm`! |
| **4. Link to User-Created Files** | Opens or downloads a separate file you created (PDF brochure, spreadsheet, Word form)! | Clicking `"Download Registration Form (PDF)"` or `"View Full Budget (.xlsx)"`! |

## 4. Evaluating a Website Before Publishing (Syllabus Objective 4.12!)

Never hit **"Publish"** without running a full quality check! Examiners expect these **THREE official pre-publishing checks** (plus usability checks):

1. **Verify That ALL Hyperlinks Work Correctly:** Click every single link (internal pages, external URLs, "Back to Top" bookmark, `mailto:` email link, and downloadable file link) to ensure **ZERO broken links (`404 Not Found`)**!
2. **Use a Test Audience:** Ask 2–3 classmates, teachers, or target users to navigate the site on **both a laptop and a phone** — watch whether menus are intuitive (**user-friendliness**), text is easy to read, and images/tables **display effectively without overflowing or breaking**!
3. **Verify That All Content Is Accurate & Up-to-Date:** Proofread every headline, figure (ensure numbers match your Excel spreadsheet!), contact phone number, and date so visitors never read outdated or misspelled facts!

## 5. Worked Example: Planning & Auditing a 3-Page SBA Website (Paper 2!)

<WorkedExample
  title="Designing & Testing the Youth Sports Day Website"
  marks={8}
  problem={
    <>
      A student builds a <strong>3-page website</strong> for her school’s Annual Sports Day using Google Sites: <strong>Page 1 (Home)</strong>, <strong>Page 2 (House Points &amp; Charts)</strong>, and <strong>Page 3 (Contact &amp; Downloads)</strong>.
      <br />
      (a) State <strong>ONE example of EACH of the FOUR hyperlink types</strong> she can include on this website.
      <br />
      (b) Before publishing the website live for parents and alumni, describe <strong>THREE evaluation checks</strong> she must perform to ensure accuracy, user friendliness, and effective display.
    </>
  }
  examTip="Whenever Paper 2 asks for '4 types of hyperlinks', give one distinct real example for EACH of the 4 official syllabus types: (1) another web page, (2) a location within the same page, (3) an email address, and (4) a user-created file!"
>

### (a) All Four Hyperlink Examples
1. **Link to another web page:** A navigation button `"House Points"` on the Home page linking to Page 2 (`House Points & Charts`), or an external link to the ISSA Champs website.
2. **Link to a location within the same web page:** A `"Back to Top ↑"` anchor link at the bottom of the long House Points page jumping back to the top banner.
3. **Link to an email address:** A `"Contact Sports Coordinator"` link pointing to `mailto:sports@school.edu.jm`.
4. **Link to a user-created file:** A `"Download Full Event Schedule (PDF)"` link opening her Word-processed schedule file!

### (b) Three Pre-Publishing Evaluation Checks
1. **Test Every Hyperlink:** Click all navigation links, the `"Back to Top"` bookmark, the email link, and the PDF download link to confirm zero broken links.
2. **Test With a Sample Audience (on Phone & Laptop):** Have a parent and a classmate browse the site to verify readable fonts, balanced text-wrapped images, and easy menu navigation.
3. **Verify Accuracy & Currency of Content:** Proofread spelling and confirm all event dates, start times, and house-point totals match the latest official Excel spreadsheet!

</WorkedExample>
