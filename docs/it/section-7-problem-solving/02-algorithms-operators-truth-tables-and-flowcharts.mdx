## 1. What Is an Algorithm? (Definition & 5 Characteristics!)

An **Algorithm** is a **finite, well-defined, step-by-step set of unambiguous instructions** that solves a specific problem and produces the desired output! *(Think of a rock-solid Jamaican jerk chicken recipe or Google Maps turn-by-turn directions!)*

### Five Essential Characteristics of Every Valid Algorithm (Syllabus Obj 7.5!)
1. **Finite Number of Steps:** Must have a countable, limited number of steps (not endless!).
2. **Precise:** Every step states **exact quantities, formulas, and rules** (never vague like *"add a few numbers"*!).
3. **Unambiguous:** Every instruction has **only ONE clear meaning** with zero guesswork!
4. **Logical Flow of Control:** Instructions move cleanly in logical order from one process to the next (via sequence, decisions, or loops).
5. **Terminates:** Must **ALWAYS reach a clear `STOP` / `END`** after a finite amount of time (no accidental infinite loops!).

## 2. All Three Operator Families (**Arithmetic, Relational & Logical!**)

### A. Arithmetic Operators (Watch **`DIV`** vs **`MOD`**!)

| Operator | Meaning | Example | Exact Result |
| :---: | :--- | :---: | :---: |
| `+` | Addition | `12 + 5` | `17` |
| `-` | Subtraction | `12 - 5` | `7` |
| `*` | Multiplication | `12 * 5` | `60` |
| `/` | Real (Decimal) Division | `17 / 5` | **`3.4`** |
| **`DIV`** | **Integer Division (WHOLE quotient ONLY — drops remainder!)** | **`17 DIV 5`** | **`3`** *(5 fits into 17 three whole times!)* |
| **`MOD`** | **Modulus (REMAINDER ONLY after integer division!)** | **`17 MOD 5`** | **`2`** *(because $17 = 3 \times 5 + \mathbf{2}$!)* |

> **Paper 1 Secret Weapon for `MOD`!** How do algorithms test if an integer `N` is **EVEN** or **ODD**?
> - If **`N MOD 2 = 0`** → `N` is **EVEN** *(remainder is 0!)*
> - If **`N MOD 2 = 1`** *(or `<> 0`)* → `N` is **ODD**!

### B. Relational (Comparison) Operators *(Always return `TRUE` or `FALSE`!)*

| Operator | Meaning | Example (`X = 10`) | Result |
| :---: | :--- | :---: | :---: |
| `=` | Equal to | `X = 10` | `TRUE` |
| **`<>`** | **Not equal to** *(also `!=` in Python/C)* | `X <> 10` | `FALSE` |
| `<` | Less than | `X < 10` | `FALSE` |
| `>` | Greater than | `X > 5` | `TRUE` |
| `<=` | Less than or equal to | `X <= 10` | `TRUE` |
| `>=` | Greater than or equal to | `X >= 15` | `FALSE` |

### C. Logical Operators (`AND`, `OR`, `NOT`) & Truth Tables! (Syllabus Obj 7.6!)

Logical operators combine simple conditions into **compound conditions** (e.g. `IF (Age >= 18) AND (HasID = TRUE)`):
- **`AND`:** Returns **`TRUE` ONLY when BOTH sides are `TRUE`**! *(If even ONE side is `FALSE`, result = `FALSE`!)*
- **`OR`:** Returns **`TRUE` when AT LEAST ONE side is `TRUE`**! *(ONLY `FALSE` when BOTH sides are `FALSE`!)*
- **`NOT`:** **Flips (inverts)** a Boolean value — `NOT TRUE = FALSE`, and `NOT FALSE = TRUE`!

*(Precedence order when parentheses are omitted: **`( )` brackets FIRST → `NOT` → `AND` → `OR`**!)*

#### Master Truth Table (`A` & `B`)

| `A` | `B` | `A AND B` | `A OR B` | `NOT A` |
| :---: | :---: | :---: | :---: | :---: |
| **`TRUE`** | **`TRUE`** | **`TRUE`** | **`TRUE`** | `FALSE` |
| **`TRUE`** | `FALSE` | `FALSE` | **`TRUE`** | `FALSE` |
| `FALSE` | **`TRUE`** | `FALSE` | **`TRUE`** | **`TRUE`** |
| `FALSE` | `FALSE` | `FALSE` | `FALSE` | **`TRUE`** |

## 3. Standard Flowchart Symbols (Memorise Every Exact Shape!)

A **Flowchart** is a **visual diagram** representing an algorithm's exact steps and flow of control using **FIVE standard shapes** (drawing the wrong shape costs marks on Paper 2!):

| Flowchart Shape | Official Name | Exact Purpose | Arrow Rules! |
| :--- | :--- | :--- | :--- |
| **`( START )`** / **`( STOP )`** *(Rounded Oval / Capsule)* | **Terminator** | Marks the **Start** and **Stop / End** of the flowchart. | `START` has 1 arrow OUT; `STOP` has 1+ arrows IN! |
| **`/ READ Score /`** *(Slanted Parallelogram)* | **Input / Output** | Any **keyboard input (`READ`, `INPUT`)** OR **screen/print output (`PRINT`, `DISPLAY`, `OUTPUT`)**! | 1 arrow IN, 1 arrow OUT. |
| **`[ Total ← Total + Price ]`** *(Plain Rectangle)* | **Process** | Any **calculation, assignment, or initialisation** (`Set Total = 0`, `Avg = Sum / 5`). | 1 arrow IN, 1 arrow OUT. |
| **`< Score >= 50? >`** *(Diamond)* | **Decision** | Evaluates a **Yes/No (`TRUE`/`FALSE`) condition** — used for **`IF` branching** AND **Loop conditions**! | **1 arrow IN, EXACTLY 2 labelled arrows OUT (`YES`/`TRUE` and `NO`/`FALSE`)!** |
| **`───►`** *(Arrow Line)* | **Flowline / Directional Arrow** | Shows the exact **direction of control** from one symbol to the next! | **MUST have arrowheads** (never plain lines without arrows!). |

## 4. Worked Example: Truth Table Evaluation + Drawing a Loop Flowchart (Paper 2!)

<WorkedExample
  title="Evaluating DIV/MOD & Logical Expressions + Converting Pseudocode to a Flowchart"
  marks={10}
  problem={
    <>
      (a) Given <code>A = 23</code>, <code>B = 5</code>, <code>Passed = TRUE</code>, and <code>FeePaid = FALSE</code>, evaluate:
      <br />
      &nbsp;&nbsp;(i) <code>A DIV B</code> &nbsp;|&nbsp; (ii) <code>A MOD B</code> &nbsp;|&nbsp; (iii) <code>(A &gt; 20) AND FeePaid</code> &nbsp;|&nbsp; (iv) <code>Passed OR (NOT FeePaid)</code>
      <br />
      (b) Represent this real May/June-style sentinel loop algorithm clearly as a structured <strong>Flowchart</strong>:
      <br />
      <em>Set <code>Total = 0</code>; Input <code>Amount</code>; While <code>Amount &lt;&gt; 0</code> add <code>Amount</code> to <code>Total</code> and input next <code>Amount</code>; Print <code>Total</code>; Stop!</em>
    </>
  }
  examTip="In a WHILE-loop flowchart, the Decision Diamond (< Amount <> 0? >) sits BEFORE the loop body! Its YES branch runs the loop steps and loops its arrow BACK ABOVE the Diamond; its NO branch exits cleanly to PRINT Total and STOP!"
>

### (a) Exact Evaluations
- **(i) `23 DIV 5` = `4`** *(5 goes into 23 four whole times)*
- **(ii) `23 MOD 5` = `3`** *(remainder = $23 - 20 = 3$)*
- **(iii) `(23 > 20) AND FALSE`** → `TRUE AND FALSE` = **`FALSE`**
- **(iv) `TRUE OR (NOT FALSE)`** → `TRUE OR TRUE` = **`TRUE`**

### (b) Structured Flowchart Diagram (Using All 5 Official Symbols!)

```text
                (    START    )            <-- Oval (Terminator)
                       │
                       ▼
              [   Total ← 0   ]            <-- Rectangle (Process)
                       │
                       ▼
             /  INPUT Amount   /           <-- Parallelogram (Input)
                       │
            ┌──────────▼──────────┐
            │    < Amount <> 0? > │── NO ──────────────┐   <-- Diamond (Decision)
            │          │          │                    │
            │         YES         │                    │
            │          ▼          │                    ▼
            │ [Total ← Total+Amt] │             / PRINT Total /  <-- Parallelogram (Output)
            │          │          │                    │
            │          ▼          │                    ▼
            │ / INPUT Amount /    │             (    STOP     )  <-- Oval (Terminator)
            │          │          │
            └──────────┘ (loops back above Diamond!)
```

*(Verify every shape & rule: Oval for START/STOP ✓, Rectangle for `Total ← 0` & `Total ← Total + Amount` ✓, Parallelogram for `INPUT` & `PRINT` ✓, Diamond with labelled `YES` & `NO` arrows for `Amount <> 0?` ✓!)*

</WorkedExample>
