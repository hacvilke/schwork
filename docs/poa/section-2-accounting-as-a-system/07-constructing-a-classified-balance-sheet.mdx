:::info Essential Understanding
A long, scrambled shopping list of assets and debts is hard to analyze. A **Classified Balance Sheet** groups every item neatly into standard categories (**Non-Current Assets, Current Assets, Current Liabilities, Non-Current Liabilities, and Capital**) and arranges them in a strict logical sequence — either the **Order of Permanence** (longest-lasting first) or the **Order of Liquidity** (cash first).
:::

| Quick Focus | What Matters Most |
| :--- | :--- |
| **Key Concept** | Grouping items into the **5 Balance Sheet classes**, computing **Working Capital**, and ordering by **Permanence** vs. **Liquidity** |
| **Exam Focus** | Constructing a clean vertical **Classified Balance Sheet** with accurate headings, subtotals, Working Capital, and exact matching totals |
| **Learning Outcome** | Classify every Balance Sheet account properly and present a balanced statement in either Order of Permanence or Order of Liquidity |

## 1. The Five Classifications Inside a Balance Sheet

| Classification | Plain Meaning | Time Horizon | Classic Examples |
| :--- | :--- | :--- | :--- |
| **1. Non-Current (Fixed) Assets** | Long-term assets bought for **use in operations** (NOT bought for resale) | Held **more than 1 year** | Land & Buildings (Premises), Machinery, Fixtures & Fittings, Motor Vehicles, Office Equipment |
| **2. Current Assets** | Short-term resources already in cash or expected to convert to cash within one trading cycle | **Within 1 year** | Closing Inventory (Stock), Trade Receivables (Debtors), Prepaid Expenses, Bank, Cash in Hand |
| **3. Current Liabilities** | Short-term debts that must be settled soon | Due **within 1 year** | Trade Payables (Creditors), Bank Overdraft, Accrued Expenses (unpaid bills), Short-term loans |
| **4. Non-Current Liabilities** | Long-term borrowing repaid over several years | Due **after more than 1 year** | 5-Year Bank Loan, Mortgage on Premises, Debentures |
| **5. Capital (Owner’s Equity)** | Owner’s net investment left inside the business | Permanent | Opening Capital + Net Profit (or − Net Loss) − Drawings = Closing Capital |

:::tip Key Formula Inside the Vertical Balance Sheet
**Working Capital (Net Current Assets) = Current Assets − Current Liabilities**
*Working Capital shows whether the business has enough short-term assets to cover its upcoming short-term bills comfortably!*
:::

**Harborview Stationery**
**Balance Sheet as at 31 December 2026** *(1 mark for complete heading)*

| Section / Item | $ | $ |
| :--- | ---: | ---: |
| **Non-Current Assets** *(Order of Permanence — 2 marks)* | | |
| Premises | 60,000 | |
| Delivery Van | 18,000 | |
| Office Equipment | 6,000 | **84,000** |
| | | |
| **Current Assets** *(Hardest to Easiest Cash — 2 marks)* | | |
| Closing Inventory | 9,500 | |
| Trade Receivables | 5,400 | |
| Bank | 3,600 | |
| Cash in Hand | 500 | |
| *Total Current Assets* | *19,000* | |
| **Less: Current Liabilities** *(2 marks)* | | |
| Trade Payables | 4,800 | |
| Accrued Electricity | 200 | |
| *Total Current Liabilities* | *(5,000)* | |
| **Working Capital** *($19,000 − $5,000)* *(1 mark)* | | **14,000** |
| **Total Net Assets** *($84,000 + $14,000)* *(1 mark)* | | **98,000** |
| | | |
| **Financed By:** | | |
| **Owner’s Capital** *(2 marks)* | | |
| Opening Capital | 68,000 | |
| Add: Net Profit | 16,000 | |
| | 84,000 | |
| Less: Drawings | (6,000) | |
| **Closing Capital** | | **78,000** |
| **Non-Current Liabilities** *(1 mark)* | | |
| 5-Year Bank Loan | | **20,000** |
| **Total Capital Employed** *($78,000 + $20,000)* | | **98,000** |

**Balance Check:** Total Net Assets (**$98,000**) = Total Capital Employed (**$98,000**) ✓

*(Bonus note: If asked for the **Order of Liquidity**, Current Assets would start with Cash in Hand $500 → Bank $3,600 → Trade Receivables $5,400 → Closing Inventory $9,500, and Non-Current Assets would reverse to Office Equipment $6,000 → Delivery Van $18,000 → Premises $60,000!)*

:::tip Quick Exam Checklist
- Always start with the **2-line heading**: Business Name + **`Balance Sheet as at [Exact Date]`**.
- **Order of Permanence** = Concrete down to Water (**Land → ... → Inventory → Receivables → Bank → Cash**).
- **Order of Liquidity** = Water down to Concrete (**Cash → Bank → Receivables → Inventory → ... → Land**).
- **Double-underline** both matching totals (`Total Net Assets` = `Total Capital Employed`)!
:::
