:::info Essential Understanding
The **Cash Book** is the heartbeat of daily business accounting — tracking every dollar flowing into or out of both the **Cash Register (Cash column)** and the **Business Bank Account (Bank column)**, plus **Cash Discounts** in a Three-Column Cash Book. Because Cash and Bank live side by side on the exact same page, you also meet one of POA’s signature moves: the **Contra Entry (`C`)**!
:::

| Quick Focus | What Matters Most |
| :--- | :--- |
| **Key Concept** | Entering receipts (**Debit**) and payments (**Credit**), recording **Contra Entries (`C`)**, totaling (NOT balancing!) **Discount columns**, and balancing **Cash** & **Bank** columns (`c/d` → `b/d`) |
| **Exam Focus** | Drawing up and balancing a complete **2-Column or 3-Column Cash Book** with opening balances (including overdrafts), cash discounts, and contra entries |
| **Learning Outcome** | Prepare, complete, and accurately balance a Three-Column Cash Book from a month of business transactions |

## 1. Golden Rules of the Three-Column Cash Book

1. **Left Side = Debit (Dr) = ALL RECEIPTS** (Money coming IN + **Discount Allowed**).
2. **Right Side = Credit (Cr) = ALL PAYMENTS** (Money going OUT + **Discount Received**).
3. **Contra Entries (`C`)** occur ONLY when cash moves **between the business’s own Cash box and its own Bank account**:
   - **Banking Cash** (taking cash from till and depositing it into the bank):
     - **Dr Bank** (Details: `Cash`, Folio: **`C`**) — Bank increases!
     - **Cr Cash** (Details: `Bank`, Folio: **`C`**) — Cash decreases!
   - **Withdrawing Cash from Bank for Office Use** (NOT personal drawings!):
     - **Dr Cash** (Details: `Bank`, Folio: **`C`**) — Cash increases!
     - **Cr Bank** (Details: `Cash`, Folio: **`C`**) — Bank decreases!
   - *(Trap Alert: Owner withdrawing bank money for **personal use** is **Drawings** — Cr Bank only, **NOT** a Contra Entry!)*
4. **Discount Columns Are TOTALED ONLY — NEVER Balanced!**
   - Simply add down the Debit Discount Allowed column and transfer its total to the **Debit** of Discount Allowed A/c.
   - Simply add down the Credit Discount Received column and transfer its total to the **Credit** of Discount Received A/c.
5. **Cash & Bank Columns Are Balanced Independently:**
   - Find the larger total of the Cash column, write the balancing difference on the shorter side as **`Balance c/d`**, draw totals on both sides, then bring **`Balance b/d`** down on the opposite side for Day 1 of the next month. Repeat independently for the Bank column!

**BlueWave Retailers — Three-Column Cash Book (April 2026)**

| Date | Details (Dr) | F | Disc. All. ($) | Cash ($) | Bank ($) | Date | Details (Cr) | F | Disc. Rec. ($) | Cash ($) | Bank ($) |
| :--- | :--- | :-: | ---: | ---: | ---: | :--- | :--- | :-: | ---: | ---: | ---: |
| Apr 1 | Balance b/d | | | 400 | 2,200 | Apr 6 | Rent | | | | 750 |
| Apr 3 | Sales | | | 900 | | Apr 14 | Apex Supply | | 40 | | 760 |
| Apr 10 | M. Gomez | | 40 | | 960 | Apr 18 | Bank *(cash banked)* | **C** | | 600 | |
| Apr 18 | Cash *(cash banked)* | **C** | | | 600 | Apr 22 | Purchases | | | 250 | |
| Apr 25 | Bank *(office cash)* | **C** | | 300 | | Apr 25 | Cash *(office cash)* | **C** | | | 300 |
| | | | | | | Apr 28 | Drawings | | | | 500 |
| | | | | | | **Apr 30** | **Balance c/d** | | | **750** | **1,450** |
| | **Totals** | | **40** | **1,600** | **3,760** | | **Totals** | | **40** | **1,600** | **3,760** |
| **May 1** | **Balance b/d** | | | **750** | **1,450** | | | | | | |

**Step-by-Step Arithmetic Check:**
- **Cash Column:** Dr total = `$400 + $900 + $300 = $1,600`; Cr items = `$600 + $250 = $850` → **Balance c/d = `$1,600 − $850 = $750`** → May 1 **Dr Balance b/d = $750** ✓.
- **Bank Column:** Dr total = `$2,200 + $960 + $600 = $3,760`; Cr items = `$750 + $760 + $300 + $500 = $2,310` → **Balance c/d = `$3,760 − $2,310 = $1,450`** → May 1 **Dr Balance b/d = $1,450** ✓.
- **Contra Entries Checked:** Apr 18 ($600 cash banked) and Apr 25 ($300 withdrawn for office use) both appear on BOTH sides with **`C`**. Apr 28 Drawings ($500) is **NOT** a contra entry — it affects only Cr Bank!
- **Discounts Checked:** Discount Allowed totaled = **$40**; Discount Received totaled = **$40** (both simply summed, never balanced).

:::tip Quick Exam Checklist
- **Dr = Receipts + Discount Allowed**; **Cr = Payments + Discount Received**.
- **Contra Entry (`C`)** = ONLY transfers between your own Cash & Bank (NEVER personal Drawings!).
- **Discount Columns** = **TOTAL ONLY** (never balance!).
- Always finish with **Day 1 of next month `Balance b/d`** below the double-underlined totals!
:::
