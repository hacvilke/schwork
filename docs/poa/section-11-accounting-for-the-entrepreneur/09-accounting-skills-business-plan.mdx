## 1. Anatomy of a Simple Business Plan & Break-Even Formulas

### The Six Essential Sections of a Business Plan
1. **Executive Summary:** Crisp 1-page elevator pitch written LAST summarizing the product, target market, funding needed, and projected Year 1 profit.
2. **Business Description &amp; Legal Structure:** Mission, unique value proposition, and legal form *(Sole Trader, Partnership, Private `Ltd`, or Co-op — Sections 2, 8 &amp; 9!)*.
3. **Market &amp; Competitor Analysis:** Target customers, pricing strategy *(Cost-Plus / Competitive — Section 10!)*, and marketing plan.
4. **Operations &amp; Management Team:** Suppliers, equipment, staffing/payroll plan *(Section 11.1–11.6!)*, and founder experience.
5. **Risk &amp; Contingency Plan:** Key threats *(supply disruption, slow sales)* and backup controls.
6. **The Financial Plan *(POA Core — What Bankers Inspect FIRST!)*:**
   - **Startup Capital &amp; Funding Budget** (Opening Balance Sheet)
   - **Break-Even Analysis** (minimum sales to survive!)
   - **6–12 Month Cash Flow Projection** (proves you won’t run out of cash!)
   - **Projected Year 1 Income Statement &amp; Pro-Forma Balance Sheet** (proves profit &amp; repayment power!)

<FormulaCard
  title="Break-Even Analysis & Margin of Safety Formulas"
  onFormulaSheet={false}
  summary="Break-Even tells an entrepreneur the EXACT survival floor where Total Revenue = Total Costs ($0 Profit, $0 Loss)!"
>

$$
\text{Contribution per Unit} = \text{Selling Price per Unit} - \text{Variable Cost per Unit}
$$

$$
\textbf{Break-Even Point (Units)} = \frac{\text{Total Fixed Costs}}{\text{Contribution per Unit}}
$$

$$
\textbf{Break-Even Sales (\$)} = \text{Break-Even Units} \times \text{Selling Price} \qquad\qquad \textbf{Margin of Safety} = \text{Budgeted Sales} - \text{Break-Even Sales}
$$

</FormulaCard>

### 1. Break-Even Analysis & Margin of Safety *(5 marks)*
- **Contribution per Bottle:** `$10.00 − $4.00` = **`$6.00/bottle`** *(1 mark)*
- **Total Annual Fixed Costs:** `$12,000 + $8,000 + $600 + $2,200 + $1,200` = **`$24,000`** *(1 mark)*
- **Break-Even Point (Units):** `$24,000 ÷ $6.00` = **`4,000 bottles/year`** *(`~334 bottles/month`)* *(1.5 marks)*
- **Break-Even Revenue:** `4,000 × $10.00` = **`$40,000`** *(0.5 mark)*
- **Margin of Safety:** `6,500 forecast − 4,000 break-even` = **`2,500 bottles`** (`$25,000` revenue buffer — `38.5%` above break-even!) *(1 mark)*

---

### 2. Projected Income Statement for Year 1 Ended 31 December 2026 *(5 marks)*

| Projected Income Statement | $ | $ |
| :--- | ---: | ---: |
| **Projected Sales Revenue** *(`6,500 bottles × $10.00`)* | | **65,000** |
| Less: **Variable Cost of Sales** *(`6,500 × $4.00`)* | | **(26,000)** |
| **Projected Gross Profit *(Total Contribution)*** | | **39,000** |
| **Less: Annual Fixed Expenses** | | |
| Kitchen Rent | 12,000 | |
| Utilities, Marketing &amp; Admin | 8,000 | |
| Insurance | 600 | |
| Equipment Depreciation *(`10% × $22,000`)* | 2,200 | |
| Bank Loan Interest *(`8% × $15,000`)* | 1,200 | **(24,000)** |
| **Projected Year 1 Net Profit** | | **$15,000** |

*(Instant Proof: Margin of Safety `2,500 bottles × $6.00 Contribution = $15,000` Net Profit exact ✓!)*

---

### 3. Pro-Forma Balance Sheet as at 31 December 2026 *(6 marks)*
*Closing Bank Working:* `Opening Bank ($12,000) + Year 1 Net Profit ($15,000) + Non-Cash Depreciation ($2,200) − Owner Drawings ($5,000)` = **`$24,200`** *(Check via raw cash: Inflows `$65,000` − Cash Outflows [`$26k VC + $21.8k Cash FC + $5k Drawings = $52,800`] = `+$12,200` + `$12,000` Open = **`$24,200`** ✓!)*

| Net Assets (31 Dec 2026) | $ | $ |
| :--- | ---: | ---: |
| **Non-Current Assets** | | |
| Bottling &amp; Kitchen Equipment *(`$22,000 cost − $2,200 depr.`)* | | **19,800** |
| **Current Assets** | | |
| Closing Inventory | 6,000 | |
| Bank *(working above)* | 24,200 | **30,200** |
| *(Current Liabilities: `$0` — all bills paid cash)* | | |
| **Total Net Assets** | | **$50,000** |

| Financed By (31 Dec 2026) | $ | $ |
| :--- | ---: | ---: |
| **Owner’s Capital** | | |
| Opening Equity (1 Jan 2026) | 25,000 | |
| Add: Projected Year 1 Net Profit | 15,000 | |
| Less: Owner Drawings | (5,000) | **35,000** |
| **Non-Current Liabilities** | | |
| 8% Small Business Bank Loan | | **15,000** |
| **Total Capital Employed** | | **$50,000** |

**EXACT BALANCE PROOF:** Total Net Assets (**$50,000**) = Total Capital Employed (**$50,000**) ✓!

### 4. Two Key Viability Ratios for the Bank Pitch *(2 marks — 1 mark each)*
- **Projected Net Profit Margin:** `($15,000 ÷ $65,000) × 100` = **`23.1%`** *(strong earnings cushion on every sales dollar!)*.
- **Return on Capital Employed (`ROCE`):** `[($15,000 + $1,200 interest) ÷ $50,000] × 100` = **`32.4%`** — generating **over 4× the `8%` cost of borrowing**, proving safe loan repayment capacity!

## 5. True or False Check

<TrueFalseQuiz
  title="True or False: Accounting Skills in a Business Plan"
  items={[
    {
      statement: 'Break-Even Point in units equals Total Fixed Costs divided by (Selling Price minus Variable Cost per unit).',
      answer: true,
      explanation: 'Correct! Selling Price − Variable Cost = Contribution per unit; Fixed Costs ÷ Contribution per unit = exact Break-Even units!',
    },
    {
      statement: 'At the Break-Even Point, a business earns a healthy Net Profit equal to its Total Fixed Costs.',
      answer: false,
      explanation: 'At Break-Even, Total Revenue equals Total Costs — Net Profit is exactly $0 (neither profit nor loss)!',
    },
    {
      statement: 'When projecting Closing Cash from Projected Net Profit, you must ADD BACK non-cash Depreciation because no cash left the bank for Depreciation.',
      answer: true,
      explanation: 'Spot on! Cash generated from operations includes Net Profit PLUS non-cash Depreciation!',
    },
    {
      statement: 'A higher Margin of Safety (Budgeted Sales minus Break-Even Sales) means a startup has a larger safety buffer if actual sales fall below forecast.',
      answer: true,
      explanation: 'Yes — bankers love a wide Margin of Safety because it dramatically lowers default risk!',
    },
    {
      statement: 'An entrepreneur only needs to write a Business Plan when asking a bank for a loan — self-funded startups gain no value from financial projections.',
