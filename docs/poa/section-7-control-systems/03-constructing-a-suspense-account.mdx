:::info Essential Understanding
When a Trial Balance fails to balance right before a reporting deadline, accountants cannot freeze the entire business! Instead, they temporarily plug the missing difference into a holding account called the **Suspense Account** on the **SHORTER side of the Trial Balance**. As each single-sided error is discovered and corrected via the General Journal, posting the Suspense half steadily **drains the Suspense Account cleanly down to `$0`**!
:::

| Quick Focus | What Matters Most |
| :--- | :--- |
| **Key Concept** | Opening the **Suspense Account** on the **short side** of the Trial Balance, posting ONLY Suspense-linked correcting entries, and clearing the account to **`$0`** (or showing any unresolved balance on the Balance Sheet) |
| **Exam Focus** | Never putting opening difference on the wrong side, ignoring COPCOR errors that do NOT touch Suspense, and verifying `Total Dr = Total Cr` when all errors are found |
| **Learning Outcome** | Open, post to, and close a complete Suspense Account from any Trial Balance disagreement and list of discovered errors |

## 1. The Golden Rule for Opening a Suspense Account

Look closely at which column of the Trial Balance is **SMALLER (SHORT)**:

| Trial Balance Imbalance | Which Side Is SHORT? | Opening Line Inside Suspense A/c |
| :--- | :---: | :--- |
| **Total Credits &gt; Total Debits** *(e.g. Dr $98,150 vs Cr $98,600)* | **Debit is short by `$450`** | **DEBIT side:** `Difference per Trial Balance  $450` |
| **Total Debits &gt; Total Credits** *(e.g. Dr $85,540 vs Cr $85,000)* | **Credit is short by `$540`** | **CREDIT side:** `Difference per Trial Balance  $540` |

### Two Crucial Exam Rules About Suspense Accounts
1. **When ALL errors are found:** The Debit total and Credit total of the Suspense Account **MUST be 100% equal** — the account closes automatically with **`$0` balance**! *(This is your built-in self-check on Paper 2!)*
2. **When SOME errors are STILL NOT found by Balance Sheet date:**
   - A remaining **Debit** balance (`Bal b/d` on Debit) is shown temporarily under **Current Assets**.
   - A remaining **Credit** balance (`Bal b/d` on Credit) is shown temporarily under **Current Liabilities**.

<WorkedExample
  title="Correcting Journal Entries & Clearing a Suspense Account to Zero"
  marks={14}
  problem={
    <>
      <p>
        <strong>Scenario:</strong> The Trial Balance of <strong>SunRidge Hardware</strong> on
        <strong> 31 December 2026</strong> failed to agree: <strong>Total Debits exceeded Total Credits

        revealed five errors:
      </p>
      <ol>
        <li>The Sales Book total was overcast by <strong>$200</strong>.</li>
        <li>Discount Allowed of <strong>$180</strong> was credited accurately to the customer’s account, but omitted from the Discount Allowed Account.</li>
        <li>The Returns Outwards Book total was undercast by <strong>$320</strong>.</li>
        <li>Cash of <strong>$300</strong> received from credit customer <strong>M. Shaw</strong> was debited accurately in the Cash Book, but wrongly posted to the <strong>Debit</strong> side of M. Shaw’s account.</li>
        <li>A new office desk costing <strong>$900</strong> (paid by cheque) was wrongly debited to <em>Stationery</em>.</li>
      </ol>
      <p>
        <strong>Required:</strong> (a) Prepare the <strong>General Journal entries</strong> (without narrations) to correct all 5 errors <em>[8 marks]</em>; (b) Construct the <strong>Suspense Account</strong> showing that it clears cleanly to $0 <em>[6 marks]</em>.
      </p>
    </>
  }
>

### (a) Correcting General Journal Entries *(8 marks)*

| # | Details | Dr ($) | Cr ($) | Touches Suspense? |
| :-: | :--- | ---: | ---: | :---: |
| **1** | Sales *(overcast → reduce Cr)* | 200 | | **YES** (Cr) |
| | &nbsp;&nbsp;&nbsp;&nbsp;Suspense | | 200 | |
| **2** | Discount Allowed *(omitted Dr)* | 180 | | **YES** (Cr) |
| | &nbsp;&nbsp;&nbsp;&nbsp;Suspense | | 180 | |
| **3** | Suspense | 320 | | **YES** (Dr) |
| | &nbsp;&nbsp;&nbsp;&nbsp;Returns Outwards *(undercast → add Cr)* | | 320 | |
| **4** | Suspense *(`2 × $300` wrong-side fix!)* | 600 | | **YES** (Dr) |
| | &nbsp;&nbsp;&nbsp;&nbsp;M. Shaw *(`$300` cancels Dr + `$300` records Cr)* | | 600 | |
| **5** | Office Furniture *(Error of Principle)* | 900 | | **NO!** |
| | &nbsp;&nbsp;&nbsp;&nbsp;Stationery | | 900 | |

---

### (b) Suspense Account *(Debits exceeded Credits → Credit Side SHORT by $540! — 6 marks)*

| Date (Dr) | Details | $ | Date (Cr) | Details | $ |
| :--- | :--- | ---: | :--- | :--- | ---: |
| Dec 31 | Returns Outwards *(Error 3)* | 320 | Dec 31 | **Difference per Trial Balance** | **540** |
| Dec 31 | M. Shaw *(Error 4 — `2 × $300`)* | 600 | Dec 31 | Sales *(Error 1)* | 200 |
| | | | Dec 31 | Discount Allowed *(Error 2)* | 180 |
| | | **$920** | | | **$920** |

**Self-Check Passed:** Total Dr (**$920**) = Total Cr (**$920**) → Suspense cleared to **`$0`** ✓ *(and Error 5 was rightly kept out!)*

</WorkedExample>

:::tip Quick Exam Checklist
- Put `"Difference per Trial Balance"` on the **SHORT side** of the Trial Balance!
- **Only entries mentioning `Suspense`** ever go inside the Suspense T-account.
- If **all** single-sided errors are found, **`Dr Total = Cr Total`** (`$0` balance)!
:::
