## 1. Key Balance Sheet Formulas (Hover or Tap to Explain!)

Before drafting your first Balance Sheet, make sure these three British/Caribbean vertical Balance Sheet subtotals are second nature:

<FormulaCard
  title="Vertical Balance Sheet Subtotals"
  onFormulaSheet={false}
  summary="Working Capital measures day-to-day cash breathing room; adding Fixed Assets gives Net Assets / Capital Employed, which MUST match Closing Capital plus Long-Term Liabilities."
>

<FormulaHint
  block
  label="Working Capital (Net Current Assets)"
  short="Subtract short-term debts (Current Liabilities) from short-term resources (Current Assets). Positive Working Capital means the business can comfortably pay its upcoming bills!"
>

$$
\text{Working Capital} = \text{Current Assets} - \text{Current Liabilities}
$$

</FormulaHint>

<FormulaHint
  block
  label="Capital Employed (Top Half = Bottom Half)"
  short="Fixed Assets plus Working Capital equals total long-term funds invested in the business (Capital Employed) — and MUST equal Closing Capital plus Long-Term Liabilities."
>

$$
\text{Fixed Assets} + \text{Working Capital} = \text{Closing Capital} + \text{Long-Term Liabilities}
$$

</FormulaHint>

</FormulaCard>

:::tip Why Negative Working Capital Is Dangerous
If **Current Liabilities > Current Assets**, Working Capital is negative — the business may struggle to pay its creditors, wages, and daily expenses even if it owns an expensive building!
:::

## 2. Standard British / Caribbean Vertical Balance Sheet Layout

Always include the **three-part heading** (marks are awarded for clean presentation on Paper 2!):
1. **Owner / Business Name** (e.g. *M. Campbell*)
2. **Statement Title & Exact Date** — always **"Balance Sheet as at [Date]"** *(never "for the year ended"!)*
3. **Currency Column Signs** (`J$` or `$`) and clean **brackets `( )`** for numbers being subtracted.

### Method A: Vertical Format (Standard Jamaican / British Exam Layout)

**M. Campbell**
**Balance Sheet as at 31 December 2025**

| Particulars | J\$ | J\$ |
| :--- | :---: | :---: |
| **FIXED ASSETS (Non-Current Assets)** | | |
| Premises (Land & Buildings) | | 180,000 |
| Fixtures & Fittings | | 25,000 |
| Motor Vehicles | | 65,000 |
| **Total Fixed Assets** | | **270,000** |
| | | |
| **CURRENT ASSETS** | | |
| Stock (Inventory) | 32,000 | |
| Debtors (Accounts Receivable) | 18,500 | |
| Cash at Bank | 14,000 | |
| Cash in Hand | 3,500 | |
| *Total Current Assets* | *68,000* | |
| **LESS: CURRENT LIABILITIES** | | |
| Creditors (Accounts Payable) | (28,000) | |
| **Working Capital (Net Current Assets)** | | **40,000** |
| **CAPITAL EMPLOYED (Net Assets before Long-Term Debt)** | | **310,000** |
| | | |
| **FINANCED BY:** | | |
| Capital | | 250,000 |
| **LONG-TERM LIABILITIES** | | |
| 5-Year Bank Loan | | 60,000 |
| **CAPITAL EMPLOYED** | | **310,000** |

*(Both halves balance cleanly at **J\$310,000**!)*

### Method B: Horizontal (T-Format) Balance Sheet (Older Past Papers)

Some older past papers use the two-sided **Horizontal Format** showing Total Assets on the left and Capital + Liabilities on the right ($A = C + L$):

| Assets | J\$ | Capital & Liabilities | J\$ |
| :--- | :---: | :--- | :---: |
| **Fixed Assets** | | **Capital** | 250,000 |
| Premises | 180,000 | | |
| Fixtures & Fittings | 25,000 | **Long-Term Liabilities** | |
| Motor Vehicles | 65,000 | 5-Year Bank Loan | 60,000 |
| *Total Fixed Assets* | *270,000* | | |
| **Current Assets** | | **Current Liabilities** | |
| Stock | 32,000 | Creditors | 28,000 |
| Debtors | 18,500 | | |
| Cash at Bank | 14,000 | | |
| Cash in Hand | 3,500 | | |
| *Total Current Assets* | *68,000* | | |
| **Total Assets** | **338,000** | **Total Capital & Liabilities** | **338,000** |

*(Check: Assets = **J\$338,000** = Capital **J\$250,000** + Liabilities **J\$88,000**!)*
