:::info Essential Understanding
Selling on credit grows revenue — but not every credit customer pays! Under the **Prudence Concept**, a business must NEVER inflate its Balance Sheet with Trade Receivables it realistically cannot collect. That means knowing the exact difference between **confirmed Bad Debts**, an **estimated Provision for Doubtful Debts**, and the pleasant surprise of **Bad Debts Recovered**!
:::

| Quick Focus | What Matters Most |
| :--- | :--- |
| **Key Concept** | **Bad Debts Written Off**, **Provision for Doubtful Debts** (Creation, Increase &amp; Decrease), and **Bad Debts Recovered** |
| **Exam Focus** | Writing off new Bad Debts **FIRST** before calculating the Provision `%`, posting ONLY the **change** in Provision to the Income Statement while deducting the **FULL new Provision** on the Balance Sheet |
| **Learning Outcome** | Prepare Bad Debts, Provision for Doubtful Debts, and Bad Debts Recovered journal/ledger entries and display Net Receivables properly |

## 1. Bad Debts vs. Provision for Doubtful Debts

| Feature | Bad Debts (Irrecoverable Debts) | Provision for Doubtful Debts |
| :--- | :--- | :--- |
| **Certainty** | **100% Confirmed uncollectible** (debtor is bankrupt, deceased, or vanished) | **Prudent Estimate** of customers who *might* fail to pay in future (usually `%` of Receivables or aged schedule) |
| **Customer’s Personal A/c** | **Credited &amp; closed to $0** (debtor removed from books) | **Untouched!** You do not know *which* specific customer will default |
| **Accounting Concept** | **Prudence &amp; Matching** | **Prudence &amp; Matching** |
| **Journal Entry** | `Dr Bad Debts Expense` / `Cr Debtor’s A/c` | **Increase:** `Dr Income Statement` / `Cr Provision for Doubtful Debts`<br/>**Decrease:** `Dr Provision for Doubtful Debts` / `Cr Income Statement` |
| **Income Statement Effect** | Full Bad Debts written off = **Operating Expense** | **ONLY the CHANGE** (`New − Old`)! Increase = **Expense**; Decrease = **Add to Gross Profit (Other Income)**! |
| **Balance Sheet Effect** | Deducted directly from Trade Receivables | **FULL New Provision** deducted from Remaining Trade Receivables |

<FormulaCard
  title="The Two-Step Receivables Sequence (NEVER Reverse This Order!)"
  onFormulaSheet={false}
  summary="Always subtract new Bad Debts BEFORE multiplying by the Provision percentage!"
>

$$
\text{Step 1: Remaining Trade Receivables} = \text{Trial Balance Receivables} - \text{Additional Bad Debts}
$$

$$
\text{Step 2: New Provision} = \text{Provision \%} \times \text{Remaining Trade Receivables}
$$

$$
\text{Step 3: Income Statement Change} = \text{New Provision} - \text{Old Provision (in Trial Balance)}
$$

- If **New &gt; Old** → **Increase in Provision** → **Operating Expense**!
- If **New &lt; Old** → **Decrease in Provision** → **Added to Gross Profit (Other Income)**!

</FormulaCard>

<WorkedExample

        <li><strong>2024 (Year 1 — No prior provision):</strong> Trade Receivables $25,000 before writing off $1,000 additional Bad Debts.</li>
        <li><strong>2025 (Year 2):</strong> Remaining Trade Receivables (after writing off $600 Bad Debts) = $30,000. Also, former customer M. Grant — written off in 2024 — unexpectedly paid $400 cash!</li>
        <li><strong>2026 (Year 3):</strong> Remaining Trade Receivables (after writing off $200 Bad Debts) = $22,000.</li>

      <ol>
        <li>Calculate the required Closing Provision and Income Statement charge/credit for <strong>2024, 2025, and 2026</strong>. <em>[6 marks]</em></li>

        <li>Show the <strong>Income Statement</strong> and <strong>Balance Sheet</strong> extracts for <strong>2025</strong> (including Bad Debts Recovered). <em>[3 marks]</em></li>
      </ol>
    </>
  }
>

**1. Three-Year Provision Calculations (6 marks):**
- **2024:** Remaining Receivables = `$25,000 − $1,000 = $24,000` → New Provision (`5% × $24,000`) = **$1,200** (Old = `$0` → **Increase = $1,200 Expense**) *(2 marks)*.
- **2025:** Remaining Receivables = `$30,000` → New Provision (`5% × $30,000`) = **$1,500** (Old = `$1,200` → **Increase = $300 Expense**) *(2 marks)*.
- **2026:** Remaining Receivables = `$22,000` → New Provision (`5% × $22,000`) = **$1,100** (Old = `$1,500` → **Decrease = $400 Other Income**) *(2 marks)*.

**2. Provision for Doubtful Debts Account *(Contra-Asset — Credit Balance, 5 marks)*:**

| Date (Dr) | Details | $ | Date (Cr) | Details | $ |
| :--- | :--- | ---: | :--- | :--- | ---: |
| **Dec 31, 2024** | Balance c/d | 1,200 | **Dec 31, 2024** | **Income Statement** *(Creation)* | 1,200 |
| | | **1,200** | | | **1,200** |
| **Dec 31, 2025** | Balance c/d | 1,500 | Jan 1, 2025 | Balance b/d | 1,200 |
| | | | **Dec 31, 2025** | **Income Statement** *(Increase)* | 300 |
| | | **1,500** | | | **1,500** |
| **Dec 31, 2026** | **Income Statement** *(Decrease)* | 400 | Jan 1, 2026 | Balance b/d | 1,500 |
| **Dec 31, 2026** | Balance c/d | 1,100 | | | |
| | | **1,500** | | | **1,500** |
| | | | Jan 1, 2027 | Balance b/d | 1,100 |

**3. 2025 Financial Statement Extracts (3 marks):**
- **Income Statement (for the year ended 31 Dec 2025):**
  - *Add: Other Income:* Bad Debts Recovered **$400** *(1 mark)*
  - *Less: Operating Expenses:* Bad Debts **$600**; Increase in Provision for Doubtful Debts **$300** *(1 mark)*
- **Balance Sheet (as at 31 Dec 2025 — Current Assets):**
  - Trade Receivables `$30,000` *Less:* Provision for Doubtful Debts `($1,500)` = **Net Trade Receivables $28,500** *(1 mark)*.

:::tip Quick Exam Checklist
- **Step 1:** Subtract **New Bad Debts** from Trade Receivables.
- **Step 2:** Multiply **Remaining Receivables × %** = **New Provision**.
- **Step 3:** **Income Statement** = **CHANGE only** (`+Exp` if up, `+Other Income` if down); **Balance Sheet** = **FULL New Provision** subtracted from Receivables!
:::
