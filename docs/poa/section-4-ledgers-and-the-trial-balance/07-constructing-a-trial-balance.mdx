:::info Essential Understanding
A **Trial Balance** is NOT a ledger account and NOT a financial statement — it is a **two-column summary schedule** listing every open ledger balance (`b/d`) on a specific date, with Debit balances in the left column and Credit balances in the right column. Because every transaction obeyed double-entry (`Dr = Cr`), **Total Debits MUST equal Total Credits**!
:::

| Quick Focus | What Matters Most |
| :--- | :--- |
| **Key Concept** | Sorting every single account balance into the **Debit column (`DEAD`)** or **Credit column (`CLIC`)** and verifying **Total Debits = Total Credits** |
| **Exam Focus** | Constructing a clean Trial Balance from a scrambled list of balances — especially placing **Returns In/Out, Discounts Allowed/Received, Bank Overdraft, Carriage, Provisions, and Opening Inventory** in the exact right column! |
| **Learning Outcome** | Construct a properly titled, balanced Trial Balance from either ledger accounts or a mixed list of balances (including finding a missing Capital figure) |

## 1. The Master Trial Balance Sorting Table (Zero Guesswork!)

Always start with the **2-line heading**:
> **[Name of Business]**
> **Trial Balance as at [Date]** *(e.g. 31 December 2026)*

| DEBIT Column (`Dr`) — **DEAD** | CREDIT Column (`Cr`) — **CLIC** |
| :--- | :--- |
| **Assets:** Premises, Land, Machinery, Vehicles, Equipment, Fixtures, **Opening Inventory**, Trade Receivables (Debtors), **Bank (positive)**, Cash, Petty Cash | **Liabilities:** Trade Payables (Creditors), Bank Loan, Mortgage, **Bank Overdraft**, Accrued Expenses |
| **Expenses & Costs:** **Purchases**, **Carriage Inwards**, **Carriage Outwards**, Rent Expense, Wages/Salaries, Electricity, Insurance, Bad Debts, **Discount Allowed** | **Income & Revenues:** **Sales**, **Discount Received**, Commission Received, Rent Received |
| **Drawings** *(reduces Capital)* | **Owner’s Capital** *(Equity)* |
| **Returns Inwards** *(Sales Returns — reduces Sales)* | **Returns Outwards** *(Purchases Returns — reduces Purchases)* |
| | **Provisions** *(Provision for Depreciation & Provision for Doubtful Debts)* |

:::warning The Opening vs. Closing Inventory Rule!
- **Opening Inventory** (stock on Jan 1) sits **INSIDE** the Trial Balance in the **Debit** column.
- **Closing Inventory** (stock counted on Dec 31) is **NEVER included inside** the regular Trial Balance totals — it is written as a **footnote underneath** (`Note: Closing Inventory at 31 Dec = $X`) because it has not been adjusted into Cost of Goods Sold yet!
:::

        <li>Drawings: $3,500 &nbsp;|&nbsp; 5-Year Bank Loan: $12,000 &nbsp;|&nbsp; <strong>Capital: ?</strong></li>
        <li><em>Additional note: Closing Inventory at 31 Dec 2026 was valued at $8,400.</em></li>
      </ul>
      <p>
        Prepare the <strong>Trial Balance of PalmTree Hardware as at 31 December 2026</strong>,
        calculating the missing <strong>Capital</strong> balance so the Trial Balance agrees.
        <em>[12 marks]</em>
      </p>
    </>
  }
>

**PalmTree Hardware**
**Trial Balance as at 31 December 2026** *(1 mark for exact heading)*

| Account Name | Debit ($) | Credit ($) |
| :--- | ---: | ---: |
| Premises *(Asset)* | 40,000 | |
| Delivery Van *(Asset)* | 15,000 | |
| Opening Inventory *(1 Jan)* | 7,500 | |
| Trade Receivables *(Asset)* | 6,400 | |
| Cash in Hand *(Asset)* | 600 | |
| Purchases *(Expense)* | 36,000 | |
| Carriage Inwards *(Expense)* | 800 | |
| Returns Inwards *(Reduces Sales)* | 1,200 | |
| Wages *(Expense)* | 9,200 | |
| Rent Expense *(Expense)* | 4,800 | |
| Discount Allowed *(Expense)* | 450 | |
| Drawings *(DEAD)* | 3,500 | |
| Sales *(Income)* | | 62,000 |
| Returns Outwards *(Reduces Purchases)* | | 900 |
| Discount Received *(Income)* | | 350 |
| Trade Payables *(Liability)* | | 5,100 |
| Bank Overdraft *(Liability)* | | 2,300 |
| 5-Year Bank Loan *(Liability)* | | 12,000 |
| **Capital *(Missing balancing figure)*** | | **42,800** |
| **Totals** | **125,450** | **125,450** |

*Note: Closing Inventory at 31 December 2026 = $8,400 (shown as a note below — NOT added inside the Trial Balance totals!)*

**Step-by-Step Missing Capital Math:**
- Sum of all Debit balances = `40,000 + 15,000 + 7,500 + 6,400 + 600 + 36,000 + 800 + 1,200 + 9,200 + 4,800 + 450 + 3,500` = **$125,450**
- Sum of known Credit balances = `62,000 + 900 + 350 + 5,100 + 2,300 + 12,000` = **$82,650**
- **Missing Capital** = `$125,450 − $82,650` = **$42,800** ✓!

## 5. True or False Check

<TrueFalseQuiz
  title="True or False: Constructing a Trial Balance"
  items={[
    {
      statement: 'Carriage Outwards is entered in the Credit column of the Trial Balance because goods are leaving the business.',
      answer: false,
      explanation: 'Classic trap! Carriage Outwards is a delivery EXPENSE paid by the business — so BOTH Carriage Inwards and Carriage Outwards go in the DEBIT column!',
    },
    {
      statement: 'Closing Inventory counted on 31 December is normally shown as a note underneath the Trial Balance rather than inside the Debit or Credit totals.',
      answer: true,
      explanation: 'Opening Inventory sits inside the Trial Balance (Debit), while Closing Inventory is noted underneath for preparing the Income Statement and Balance Sheet.',
    },
    {
      statement: 'Returns Outwards and Discount Received both belong in the Credit column of the Trial Balance.',
      answer: true,
      explanation: 'Returns Outwards reduces Debit Purchases (Credit) and Discount Received is Other Income (Credit).',
    },
    {
      statement: 'Provision for Doubtful Debts and Provision for Depreciation are listed in the Debit column of the Trial Balance.',
      answer: false,
      explanation: 'All Provisions act as contra-asset accounts (reducing Receivables or Non-Current Assets) and ALWAYS belong in the CREDIT column.',
    },
    {
      statement: 'A Trial Balance is dated "as at [Specific Date]" just like a Balance Sheet.',
      answer: true,
      explanation: 'A Trial Balance captures all ledger balances on one exact closing date, so its title is always "Trial Balance as at [Date]".',
    },
  ]}

:::tip Quick Exam Checklist
- **DEAD = Debit:** Assets, Expenses, Purchases, **Carriage In & Out**, **Returns Inwards**, **Discount Allowed**, Drawings, **Opening Inventory**.
- **CLIC = Credit:** Liabilities, **Bank Overdraft**, **Provisions**, Income, Sales, **Returns Outwards**, **Discount Received**, Capital.
- **Closing Inventory** stays as a **note underneath** — NEVER inside the Trial Balance totals!
:::
